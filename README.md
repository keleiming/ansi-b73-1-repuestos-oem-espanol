Repositorio técnico abierto en español publicado por **[YSM Pumps (Jinan Yingsiman Machinery Co., Ltd.)](https://ysmbombas.com/)** para ingenieros de mantenimiento, confiabilidad, procesos y compras en **Chile, Perú, México, Colombia, Argentina, Bolivia, Ecuador y España**.

Reúne datos técnicos estructurados, descargables y verificados para bombas centrífugas químicas **ANSI/ASME B73.1**:
- **Serie YSM G196**: bomba completa y repuestos dimensionalmente intercambiables con el patrón **Goulds 3196** (y plataformas compatibles como Griswold 811, Peerless 8196, Summit 2196, Aurora 3550).
- **Serie YSM D Mark III**: bomba completa y repuestos con impulsor de álabes inversos (*reverse-vane*) compatibles con **Flowserve Durco Mark 3** (Grupos 1K, 2K y 3K).

> **Aviso de independencia (Aftermarket no OEM)**: YSM Pumps es un fabricante independiente de bombas y repuestos intercambiables (*aftermarket*). Los nombres Goulds®, 3196®, Durco® y Mark 3® pertenecen a sus respectivos titulares y se citan exclusivamente como referencia dimensional y técnica de intercambiabilidad bajo ASME B73.1.

## Índices Rápidos por Componente (223 Referencias)

1. **[Impulsores / Rodetes ANSI (60 referencias — Ítem 101)](https://ysmbombas.com/repuestos-ansi/impulsores-rodetes-ansi/)**: 27 impulsores abiertos (G196) y 33 de álabes inversos (D Mark III).
2. **[Carcasas Espirales / Volutas (60 tamaños — Ítem 100)](https://ysmbombas.com/repuestos-ansi/carcasas-voluta-ansi/)**: envolvente y bridas ASME B73.1 sin modificar tuberías.
3. **[Tapas Traseras y Cámaras de Sello (49 referencias — Ítem 184 / 106)](https://ysmbombas.com/repuestos-ansi/tapas-camara-de-sello-ansi/)**: estándar, BigBore y cónicas autolimpiantes.
4. **[Ejes / Flechas y Camisas Protectoras (21 referencias — Ítem 122 / 126)](https://ysmbombas.com/repuestos-ansi/ejes-flechas-camisas-ansi/)**: versiones con camisa y macizas para STX, MTX, LTX, XLTX y Grupos 1K/2K/3K.
5. **[Bastidores, Portarrodamientos y Adaptadores Power End (33 referencias)](https://ysmbombas.com/repuestos-ansi/bastidores-portarrodamientos-adaptadores-ansi/)**: conjunto giratorio completo para mantenimiento *back pull-out*.
